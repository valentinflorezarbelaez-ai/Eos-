# Browser QA Skill

## Purpose
Validates real user journeys, visual rendering, and interactive UI behaviors in modern browsers.

## Inputs
- Web app URLs, user journey test scripts, visual snapshots, browser logs.

## Procedure
1. **User Journey E2E**: Execute automated browser subagent or Playwright scripts across key user journeys.
2. **Responsive Rendering**: Validate UI layouts across Mobile (375px), Tablet (768px), and Desktop (1440px) viewports.
3. **Interactive States**: Test button clicks, form submissions, hover states, error states, and empty states.
4. **Console & Error Inspection**: Catch unhandled JavaScript errors, broken network requests, or failed API calls.

## Evidence Requirements
- Store visual screenshots, video recordings, or browser console logs in `docs/evidence/`.
