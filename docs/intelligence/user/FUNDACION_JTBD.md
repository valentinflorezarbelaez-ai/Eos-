## 3. Criterios de Falsación del Job

Un Job se considerará **no resuelto (falla de producto)** si:
1. El usuario tiene que hacer *scroll* durante más de 3 segundos buscando los datos de contacto o donación.
2. El usuario duda si los datos bancarios o fiscales son auténticos.
3. El proceso de copia de datos bancarios genera errores tipográficos o copia tokens inválidos.
