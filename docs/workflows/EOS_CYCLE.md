# THE 21-STEP EOS ENGINEERING CYCLE

## Pipeline Stages

```text
 1. INTAKE
 2. RECONNAISSANCE
 3. CONTEXT UNDERSTANDING
 4. REQUIREMENTS
 5. RESEARCH
 6. ARCHITECTURE
 7. DESIGN
 8. IMPLEMENTATION
 9. TESTING
10. SECURITY
11. QUALITY
12. ACCESSIBILITY
13. PERFORMANCE
14. SEO
15. BROWSER QA
16. EVIDENCE
17. DOCUMENTATION
18. DEPLOYMENT
19. POST-DEPLOYMENT VERIFICATION
20. LEARNING
21. CONTINUOUS IMPROVEMENT
```

---

## Stage Descriptions

- **Intake & Reconnaissance**: Gather workspace state, client assets, and raw requirements.
- **Context & Requirements**: Map user goals, technical dependencies, and non-functional requirements.
- **Research & Architecture**: Evaluate primary sources and design robust, scalable interfaces (ADR).
- **Implementation & Testing**: Build incrementally using Spec Driven Development (SDD) and write comprehensive test suites.
- **Quality & Non-Functional Verification**: Audit security, accessibility (WCAG AA), performance, SEO, and visual browser rendering.
- **Evidence & Documentation**: Capture verifiable test execution outputs and record operational manuals.
- **Deployment & Continuous Improvement**: Execute controlled deployments and record learnings into persistent system memory.
