## 1. Adversarial Truth Principle
EOS must not rely solely on evidence produced during the same process that it seeks to validate.

Every critical claim must be refutable via:
- Contradiction testing
- Independent reproduction
- Verification by independent actors
- Controlled adversarial failure injection
- Alternative plan analysis
- Strict invariant inspection
- Verified rollback testing
- Immutable audit logging
